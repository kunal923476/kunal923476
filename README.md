## 🧑‍💻 About Me

> **AI Engineer** building production LLM applications for financial services — turning complex SAS programs, BRDs and regulatory processes into structured, auditable AI outputs.

- 🏦 &nbsp;Domain expertise in **Credit Risk · AML screening · IFRS 9** modelling workflows
- 🤖 &nbsp;LLM stack: **Claude Opus/Sonnet** (Anthropic) · **GPT-4o** (OpenAI) · **MCP** tooling
- ⚙️ &nbsp;Backend: **FastAPI** · **Python 3.11+** · async SQLite · RAG pipelines
- 🎨 &nbsp;Frontend: **TypeScript** · **React** · 3D avatars · voice I/O
- 📊 &nbsp;Flagship: **SAS Flow Diagram Agent** — reads SAS programs, generates Basel III / IFRS 9 audit-ready flow diagrams with prompt caching and a 7-stage deterministic pipeline
